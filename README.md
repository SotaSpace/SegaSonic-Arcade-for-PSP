# SegaSonic-Arcade-for-PSP
Hi, my name is Sota. I’m a beginner trying to create a port of one of my favorite games. Today, I’m sharing a test—created with a fair amount of help from AI—of a port of the 1993 arcade game *SegaSonic* for the PSP.

In addition to the AI, there is also assistance from a user named Ghurone, a programmer behind one of the *Sonic R* ports for the PSP, whom you can follow on his GitHub page:

https://github.com/ghurone
